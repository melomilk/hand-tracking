# Hand Tracking with MediaPipe and OpenCV
Real-time hand landmark detection using a webcam, built with MediaPipe and OpenCV.

## What it does
Detects up to 2 hands in real time and draws 21 landmarks and connections on each detected hand.

## Tech stack
- Python version: 3.11
- MediaPipe - hand landmark detection
- OpenCV - webcamera access and frame display

## How to run
1. Clone the repo
2. Create a virtual environment and activate it
3. Install dependencies:
pip install -r requirements.txt
4. Run:
py hand_tracking.py
